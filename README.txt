THREADS POSTER — автопостинг в Threads (Windows)
================================================

Что умеет
• Вставляете посты пачкой (между постами строка ---), программа раскладывает
  их по лучшему времени и публикует в ваш Threads.
• Несколько проектов. У каждого свои посты, своё время, свой токен и свой журнал.
  Клиника не может опубликоваться в аккаунт матрасов — даже если оба подключены.
• Расписание, правка, перенос поста в другой проект, «опубликовать сейчас».
• Очистка очереди (ожидающие / ошибки / всё неопубликованное). Уже вышедшее не трогает.
• Пауза одного проекта, пока остальные продолжают выходить.
• Если такой же текст уже есть в другом проекте — спросит ещё раз.
• Живой журнал. Тестовый режим — прогон без реальной публикации.
• Вкладка «Как работает» — зачем проекты и как взять токен.

УСТАНОВКА (1–2 минуты)
1. Распакуйте архив: правой кнопкой по zip → «Извлечь всё…».
   Запускать прямо из zip нельзя, сначала извлечь.
2. Дважды кликните Install.bat.
   Если Windows пишет «Система Windows защитила ваш компьютер»:
   нажмите «Подробнее» → «Выполнить в любом случае». Это нужно один раз.
3. Установщик сам скачает Node.js с официального сайта nodejs.org (если его нет),
   откроет окно программы в браузере и положит значок «Threads Poster»
   на рабочий стол и в меню «Пуск». Папку из архива после этого можно удалить.

ОБНОВЛЕНИЕ СО СТАРОЙ ВЕРСИИ
Запустите Install.bat из новой версии ещё раз.
Посты и токен не сотрутся: старая единственная очередь станет проектом «Основной».
Дальше: «+ Проект» для второго аккаунта, в его настройках — его токен.
Один и тот же Threads нельзя привязать к двум проектам.

ВТОРОЙ АККАУНТ
1. Сверху «+ Проект», имя (клиника, клиент, личный).
2. Откройте его — очередь пустая, написано «без аккаунта».
3. Настройки → токен ЭТОГО аккаунта → Подключить. Проверьте @ник в шапке.
4. Вставьте посты. Они не появятся в других проектах.
5. Боевой режим включается отдельно у каждого.

ПОДКЛЮЧЕНИЕ THREADS (один раз на аккаунт)
В программе вкладка «Как работает» или Настройки → «Коротко, где взять токен».
Кратко: developers.facebook.com/apps → сценарий «Доступ к API Threads» →
разрешение threads_content_publish → тестировщик Threads на нужный ник →
принять приглашение в Threads → генератор маркера → вставить в ЭТОТ проект.

ВАЖНО
• Посты, проекты и токены хранятся в %APPDATA%\ThreadsPoster.
  Переустановка и обновление их не трогают.
• Токен действует 60 дней, программа продлевает его сама
  (компьютер должен включаться хотя бы раз в пару недель). У каждого проекта свой.
• Посты выходят, только когда компьютер включён и НЕ в спящем режиме.
  Чтобы не засыпал: Параметры → Система → Питание → «Переводить в спящий режим» → «Никогда».
  Если пост опоздал больше чем на 6 часов, он помечается «пропущен».
  Кнопка «Очередь» → «Вернуть ошибки и пропуски в свободные слоты».
• Перед публикацией программа проверяет, что токен всё ещё тот аккаунт.
  Если нет — проект встаёт на паузу и посты никуда не уходят.
• Программа работает в фоне без окна. Окно управления открывает значок «Threads Poster».
• Удаление: Uninstall.bat. Посты при этом остаются в %APPDATA%\ThreadsPoster.
