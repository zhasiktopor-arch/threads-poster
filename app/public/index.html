Расписание

Как запустить

То, что вы видите здесь, — пример. На компьютере программа ставится один раз, дальше открывается значком.

  1. Скачай архив: Threads Poster для Windows. Кнопка сверху ведёт туда же.
  2. Правой кнопкой по архиву → Извлечь всё…. Из самого архива не запускать — сначала распаковать.
  3. В распакованной папке дважды кликните Install.bat. Рядом лежит файл «КАК ЗАПУСТИТЬ.txt» с этими же шагами.
  4. Если Windows пишет «Система Windows защитила ваш компьютер» — Подробнее → Выполнить в любом случае. Это один раз.
  5. Подождите минуту. Откроется браузер. На рабочем столе и в меню «Пуск» появится Threads Poster — потом открывать его.
  6. Старые посты и токен не сотрутся. Всё, что было раньше, станет проектом «Основной».

Дальше программа сама включается вместе с компьютером и работает без окна. Чтобы посмотреть очередь — значок на рабочем столе. Посты выходят, только пока компьютер включён и не спит.

Почему посты уходили не в тот аккаунт

Раньше была одна очередь и один токен. Подключаете другой аккаунт — а в очереди ещё лежат чужие тексты. Программа честно публикует то, что в очереди, уже в новый аккаунт.

Теперь сверху выбирается проект. У каждого проекта свои посты, своё время, свой токен и свой журнал. Планировщик проходит все проекты сам: клиника публикуется в клинику, даже если на экране открыты матрасы.

Как завести второй аккаунт

  1. Нажмите + Проект. Имя — чтобы не перепутать: «Клиника», «Матрасы», имя клиента. В заметку можно вписать ник.
  2. Откройте его. Шапка должна показать это имя и «аккаунт не подключён». Очередь пустая — так и надо.
  3. Настройки → вставьте токен этого аккаунта → Подключить. Проверьте, что загорелся правильный @ник.
  4. Вставьте посты. Они не появятся в других проектах.
  5. Боевой режим включается отдельно у каждого. Один может быть боевым, второй — в тесте.

Один и тот же Threads нельзя привязать к двум проектам. Если в проекте ещё лежат посты старого аккаунта, новый токен программа не примет — сначала очистите очередь или заведите отдельный проект.

Очередь

  • Очередь в расписании: скачать тексты, скопировать, вернуть ошибки в свободные слоты, очистить ожидающие или всё неопубликованное.
  • Уже вышедшие посты очистка не трогает. Чужой проект не трогает никогда.
  • Пауза останавливает только текущий проект. Остальные продолжают выходить.
  • Кнопка ✎ → внизу список проектов. Если перенести пост, он выйдет уже в аккаунт того проекта.
  • ⧉ ставит копию в очередь этого проекта, на ближайший свободный слот.
  • Если такой же текст уже есть в другом проекте, программа спросит ещё раз. Так случайно не задвоите.

Где взять токен

  1. Откройте developers.facebook.com/apps, войдите через Facebook.
  2. Создать приложение → имя любое → сценарий «Доступ к API Threads» → бизнес-портфолио не подключать.
  3. Сценарии использования → Настроить → Разрешения: добавьте threads_content_publish.
  4. Там же Настройки: во все поля обратного вызова впишите https://localhost/ → Сохранить.
  5. Роли приложения → Добавить людей → Тестировщик Threads → ник нужного аккаунта.
  6. В Threads: Настройки → Аккаунт → Разрешения для сайтов → Приглашения → Принять.
  7. Снова Настройки сценария → Генератор маркеров → Сгенерировать напротив этого аккаунта → скопировать.
  8. Секрет приложения (необязательно, помогает получить токен на 60 дней): Настройки приложения → Основное → Секрет → Показать.

Токен живёт 60 дней. Программа продлевает его сама, если компьютер включается хотя бы раз в пару недель. У каждого проекта токен свой.

Режим, сон, обновление

Тестовый — прогон по расписанию, в Threads тишина, в журнале будет «тест». Боевой — текст уходит только в @ник этого проекта. Перед отправкой программа сверяет, что токен всё ещё тот самый аккаунт. Если нет — ставит проект на паузу и ничего не публикует.

Посты выходят, только когда компьютер включён и не спит. Если пост опоздал дольше, чем задано в настройках (обычно 6 часов), он становится «пропущен». Его можно вернуть кнопкой в «Очереди» — он встанет на ближайшее свободное время своего проекта.

Посты, токены и проекты лежат в %APPDATA%\ThreadsPoster. Обновление программы их не стирает. Старая единственная очередь после обновления станет проектом «Основной».

На Windows системных уведомлений нет. Если вкладка открыта, можно разрешить уведомления браузера в настройках — они придут, когда вкладка свёрнута.
